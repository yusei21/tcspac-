# tcspac-

## Desenvolvimento assistido por IA — Vibe Coding Toolkit

Este repositório documenta como adotar o **[Vibe Coding Toolkit](https://github.com/soumatheusgomes/vibe-coding-toolkit)** para organizar o desenvolvimento assistido por IA.

O toolkit é um conjunto de prompts, guias e modelos de configuração para projetos. **Este repositório não é o projeto original nem afirma que o toolkit já foi instalado ou executado.** Antes de modificar o código, o agente deve inspecionar a estrutura existente, apresentar um plano e executar testes.

### Aplicar a um projeto existente

Abra a pasta do projeto em um agente com acesso aos arquivos e ao terminal (por exemplo, Codex ou Claude Code) e forneça:

```text
Read https://raw.githubusercontent.com/soumatheusgomes/vibe-coding-toolkit/main/docs/prompts/12-existing-project-setup.md and execute the entire “Prompt” section block in this project, starting with brainstorming.
Preserve existing code, stack, data, credentials, and working behavior. Explain proposed changes before applying risky operations. Run relevant tests and report what was or was not verified.
```

Reveja as mudanças propostas antes de aplicá-las. Consulte também a [documentação de instalação](https://github.com/soumatheusgomes/vibe-coding-toolkit/blob/main/docs/01-installation.md).
